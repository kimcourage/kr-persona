## 9.1 설계

### 분리한 자료

모든 원자료에서 20%를 분리하고 나머지 80%로 가상 인구를 생성하고 모형을 다시 추정해 검증 표본을 생성한 뒤, 분리한 20%와 비교한다. 나누는 방법은 3.11절과 6.1절에 있다. 요약하면, 조사 자료는 `krpersona/blocks/core.py`의 `holdout_mask(name, n, frac=0.2)`가 자료 이름의 MD5 앞 16진수 8자리를 시드로 원자료 행 전체(어떤 거르기보다 먼저)에 $U_i<0.2$인 행을 선택한다. 이름은 `knhanes`, `eaps`(A형), `eaps_b`(B형), `hfcs`, `kgss`(모든 연도, 성격, 가치, KGSS 블록 공통), `klosa`다. 센서스는 가구 단위로 `H.hid.sample(frac=0.8, random_state=5)`가 학습 가구이고, 나머지 83,719가구의 국내 출생 내국인 19세 이상 154,320명이 검증 자료다.

`KR_HOLDOUT=1`에서는 80% 가구로 생성한 센서스 기본 집단 `syn_s5_f0.8`(5.4절)과 그 가구에서 생성한 모자 나이 차 분포, 그리고 성격, 가치, 건강(우울 및 불안 측정 및 구조 모형과 블록 모형), 노동, 소득, KGSS 블록(영어 능력 포함 73개), 가치 → 태도 연결, 가족, 개발자 여부 모형을 모두 80%로 다시 추정한 파일(`*_80`)을 사용한다. 벌점 크기의 교차검증도 80% 안에서 한다. 원자료 100%로 정한 것을 검증 모드에서도 그대로 사용하는 것은 사후층화 목표(성 × 5세 연령 × 시도), 성격과 가치 점수의 중심에 사용하는 인구 구성, 센서스 사회단체 참여율, KGSS 블록 구조(4.5절), MatrAIx 금지 규칙의 분류다(3.11절). 따라서 검증용 20%가 이 값들에 들어 있다. 모순 규칙 세트와 규칙에서 생성한 금지 규칙은 실제 자료를 사용하지 않는다(금지 규칙의 기준 표본 `test5`도 80% 모형으로 생성한 생성 표본이다).

### 검증 표본

검증 표본 `val_on`은 `KR_HOLDOUT=1`, 2만 명, 시드 11, MatrAIx 속성 켬으로 생성했다. 21,111명을 생성하여 거부 검사 통과율이 99.93%이고, 우세 성격 기준 δ는 0.1254다(`results/csv/generation.csv`, 7.9절). `val_novl`은 같은 조건에서 가치 → 태도 연결만 끈 표본(`KR_NO_VLINKS=1`)이며 9.8절의 연결 점검에만 사용한다. ③과 ⑤, 9.8절의 일부 점검은 최종 표본 `out_on`(100% 모형, 2만 명, 시드 1)에도 적용한다.

①②④는 한국 속성만 비교한다. 다섯 자료가 측정하는 속성은 합쳐 83개(MatrAIx 속성 id를 사용하는 한국 속성 62개와 `kr_*` 21개)이며, MatrAIx 그래프에서 추출하는 속성 1,069개는 하나도 실제 자료와 비교되지 않는다. MatrAIx 속성은 ③의 규칙과 ⑤의 렌더링으로만 점검된다.

### MatrAIx 비교 표본

같은 지표를 MatrAIx에도 측정한다. 비교 표본은 1단계에서 MatrAIx의 공식 그래프와 샘플러로 다시 생성한 100만 명 가운데 `cult_south_korea` = Native이고 연령대가 18-24 이상인 37,237명이다(산출물 폴더 `artifacts/baseline/codes.npz`, `validate/sources.py`의 `matraix_adults`, 2.2절). MatrAIx 연령대 18-24에는 18세가 들어 있고, `kr_*` 열은 없다. 공개된 Persona 1M이 아니라 같은 샘플러로 다시 추출한 표본이며, 가중치 없이 사용한다. 9.2절의 범주 대응을 MatrAIx 값에도 그대로 적용한다.

## 9.2 비교 범주 맞추기

`krpersona/validate/sources.py`는 자료마다 분리한 행을 불러와 비교 범주의 번호(결측 −1)와 가중치를 생성하고, 속성마다 페르소나 값(문자열)을 같은 범주 번호로 바꾸는 함수를 제공한다. 어느 범주에도 들지 않는 페르소나 값은 "그 밖" 번호 $K_a$를 받는다. 실제 자료에는 이 번호가 없으므로 속성 $a$의 분포는 $K_a+1$칸에서 비교한다. 같은 함수를 MatrAIx 값에도 사용하므로, MatrAIx에만 있는 범주(예: `highest_education`의 Vocational / cert, `demo_housing_status`의 Shared housing, `urbanicity`의 Nomadic / remote, `company_size`의 Startup (<50), SMB (50-500) 등)는 "그 밖"이 된다.

## 9.3 ① 조합 분포 거리

### 방법

자료 $d$가 측정하는 속성 가운데 $k$개($k=2,3$)로 된 부분집합 $S$마다 총변동거리를 측정한다(`validate.py`의 `tvd_sets`). $R_S$는 분리한 행 가운데 $S$의 속성이 모두 관측된 행, $c_S(\cdot)$는 9.2절의 범주 번호 조합, $\mathcal P_d$는 그 자료의 비교 대상인 페르소나(지역별고용조사는 취업자, 그 밖은 전원)다.

$$
p^{R}_S(\mathbf v)=\frac{\sum_{i\in R_S}w_i\,\mathbf 1[c_S(x_i)=\mathbf v]}{\sum_{i\in R_S}w_i},\qquad \hat p_S(\mathbf v)=\frac{1}{|\mathcal P_d|}\sum_{j\in\mathcal P_d}\mathbf 1[c_S(y_j)=\mathbf v],\qquad \mathrm{TVD}_S=\frac12\sum_{\mathbf v}\big|\hat p_S(\mathbf v)-p^{R}_S(\mathbf v)\big|
$$

생성 표본 쪽은 가중치 없이 집계한다. 같은 식으로 MatrAIx 비교 표본의 거리도 산출하는데, $S$의 속성이 모두 MatrAIx에 있을 때만 산출한다(`kr_*`가 든 조합은 비움).

표본오차 기준은 분리한 자료의 크기에서 오는 거리다. Kish 유효 표본 수 $n_e$만큼 합성 페르소나를 복원추출해 생성 분포와의 거리를 세 번 측정하고 평균한다.

$$
n_e=\max\Big(\Big\lfloor\frac{(\sum_{i\in R_S}w_i)^2}{\sum_{i\in R_S}w_i^2}\Big\rfloor,\ 10\Big),\qquad F_S=\frac13\sum_{b=1}^{3}\frac12\sum_{\mathbf v}\big|\hat p^{*(b)}_S(\mathbf v)-\hat p_S(\mathbf v)\big|
$$

$\hat p^{*(b)}_S$는 $\mathcal P_d$에서 $n_e$명을 복원추출한 분포다. 즉 $F_S$는 생성 분포가 참이라면 분리한 자료 크기의 표본이 보일 거리다. 생성 표본 자체의 잡음(2만 명)과 가중을 넘는 설계 효과는 포함하지 않는다.

- 부분집합: 속성 2개는 모든 조합, 3개는 모든 조합이되 1,500개(`MAX_TRIPLES`, 가정)를 넘으면 비복원으로 1,500개를 추출한다. 넘는 것은 KGSS뿐이다($\binom{62}{3}=37{,}820$).
- KGSS 연도: $S$에 든 KGSS 속성마다 생성에 혼합하는 연도(`gen_w`의 연도) 집합을 구해, 그 교집합에 드는 해의 응답자만 사용한다. 교집합이 비면 합집합을 사용한다.
- 최소 행 수: $|R_S|<30$이면 계산하지 않는다(가정).
- 난수: `default_rng(2026)` 하나를 세 조합 추출, 기준 재추출, ②가 자료 순서대로 함께 사용한다.

## 9.4 ② 구분 가능성(pMSE)

### 방법

분리한 실제 행과 합성 행을 같은 수 $h$씩 혼합하고, 분류기가 각 행이 합성일 확률 $\hat e_i$를 예측하게 한다(`validate.py`의 `pmse`).

$$
\mathrm{pMSE}=\frac{1}{2h}\sum_{i=1}^{2h}\Big(\hat e_i-\frac12\Big)^2
$$

두 집단을 같은 수로 섞으므로 구분하지 못하면 $\hat e_i\approx 1/2$이고 pMSE는 0에 가깝다.

| 항목 | 값 |
|---|---|
| 행 | 비교 속성이 모두 관측된 분리한 행. 100행 미만이면 계산하지 않음 |
| $h$ | $\min(3000,\lfloor n/2\rfloor)$(가정) |
| 실제 쪽 | 가중치에 비례해 $h$행 복원추출 |
| 생성 표본 쪽 | 비교 대상 페르소나에서 $h$명 복원추출(가중치 없음) |
| 특성 | 범주 번호를 문자열로 변환한 원핫 부호(`pd.get_dummies`) |
| 분류기 | `DecisionTreeClassifier(min_samples_leaf=20, max_depth=8, random_state=0)`(가정) |
| 예측 | `cross_val_predict(cv=5, method='predict_proba')`. 섞지 않는 층화 5겹의 겹 밖 예측 |
| 기준선 | 완전 행을 무작위로 반씩 나눠 각 반에서 가중 복원추출한 $h$행끼리 같은 계산 |
| MatrAIx | 실제 $h$행 대 MatrAIx $h$명. 비교 속성이 모두 MatrAIx에 있을 때만 |
| KGSS | 2021년 응답자, 모형 순서에서 2021년에 물은 KGSS 속성 앞 25개와 성별, 연령, 학력 |

`pmse_subset.py`는 MatrAIx와 비교할 수 있게 MatrAIx에도 있는 속성만으로 다시 측정한다. 국민건강영양조사는 `kr_*` 두 개를 뺀 11개, KGSS는 MatrAIx에도 있는 2021년 속성 가운데 분리한 응답이 많은 10개와 성별, 연령, 학력이다. 이 스크립트는 `default_rng(2026)`을 새로 생성하므로 추출이 `validate.py`와 다르다. 분류기는 결정나무 하나만 사용한다.

## 9.6 ④ 공식 통계

검증 표본의 내부 값(`internal.parquet`의 정확한 나이, 가구원 수, PHQ-9 합)과 출력 값으로 다음 비율을 내고, 분리한 자료의 같은 값과 문헌의 공식 기준값에 비교한다(`validate.py` 끝부분).

- 65세 이상 비율: 성인 페르소나 가운데 65세 이상. 분리분은 센서스 검증 쪽 사람의 가구가중값 비율.
- 1인 가구 비율(가구 기준): 사람 단위 페르소나로 가구 비율을 내려고 페르소나 $j$에 $1/k_j$($k_j$는 가구원 수)의 가중치를 부여한다. 분리분도 가구가중값 $\times 1/k$로 같은 식을 사용한다.

  $$
  \widehat{\Pr}(\text{1인 가구})=\frac{\sum_j \mathbf 1[k_j=1]/k_j}{\sum_j 1/k_j}
  $$

- 종교 있음, 개신교, 불교(Buddhist와 Won Buddhist), 천주교: 출력 `demo_religion_affiliation`의 비율. 종교 없음은 None, Atheist / agnostic, Spiritual but unaffiliated다.
- 우울: PHQ-9 합 10점 이상. 분리분은 국민건강영양조사 검증 쪽에서 PHQ-9 문항이 모두 있는 성인의 가중 비율.

1인 가구 비율이 공식값 31.7%보다 높은 것은 계산 방식 때문이다. 성인 페르소나는 가구 $h$에서 성인 수 $a_h$에 비례해 나오므로, $1/k_h$를 곱하면 가구의 가중치가 $a_h/k_h$가 된다. 1인 가구는 1이고 미성년 자녀가 있는 가구는 1보다 작으므로 1인 가구가 실제보다 많이 잡힌다. 센서스 분리분에 같은 식을 사용하면 35.55%가 나오므로, 차이는 생성기가 아니라 지표의 정의에서 온다. 종교는 KGSS 블록이 2020년 앞뒤 차수를 혼합하여 생성한 값이고(6장), 기준값은 다른 조사의 2025년 값이다. 종교 있음이 6.8%p, 불교가 4.1%p, 천주교가 3.4%p 높다. 조사와 시점이 달라 원인을 나누지 않았다. 우울은 분리분보다 0.59%p 낮다.

## 9.7 ⑤ 전달 누락

생성한 속성이 모델에 주는 프롬프트에 모두 포함되는지 확인한다(`krpersona/validate/render_check.py`). 페르소나 $i$의 속성 집합을 $\mathcal A_i$, 그 가운데 렌더러가 한 줄로 적은 속성을 $\mathcal D_i$라 할 때

$$
\text{전달 누락률}=\frac1N\sum_{i=1}^{N}\Big(1-\frac{|\mathcal D_i|}{|\mathcal A_i|}\Big)
$$

이다. 표본의 앞 5,000명에 대해 다음을 한다.

1. 누락 없음: 값이 있는 모든 속성으로 `dimensions`를 생성하고, 한국 렌더러(`krpersona/render/render.py`의 `collect_dimension_items(return_ids=True)`)가 돌려준 id와 비교한다. 같은 `dimensions`를 MatrAIx 렌더러(MatrAIx `persona_dimension_catalog.collect_dimension_items`, MatrAIx `dimensions.json`)에도 포함하고 빠진 속성을 집계한다.
2. 경로 확인: 앞 200명에 대해 MatrAIx의 실제 템플릿 `persona_system.md.j2`를 Jinja2(`StrictUndefined`)로 한국 렌더러의 문맥과 함께 렌더링하고, "- "로 시작하는 줄 수가 속성 수와 동일한지 확인한다.
3. 고정 예시: 처음 나오는 45\~54세 여성 교사(`role_function` = Teaching)의 프롬프트 전문을 결과 피클 옆의 `reference_teacher_45-54.md`로 저장한다. 실행할 때마다 덮어쓰므로, 저장된 파일은 마지막에 실행한 최종 표본의 것이다(42,793자).
4. MatrAIx 렌더러가 자주 빼는 속성: 앞 2,000명에서 속성마다 빠진 비율.

| 표본 | 인원 | 1인 속성 수 | 한국 렌더러 누락 | MatrAIx 렌더러 누락(평균, 최소\~최대) | MatrAIx 누락률 | 템플릿 줄 점검 | 예시 글자 수 |
|---|---|---|---|---|---|---|---|
| 검증 표본 | 5,000 | 1,311 | 0 | 670.3(548\~743) | 51.13% | 200명 모두 통과 | 42,911 |
| 최종 표본 | 5,000 | 1,311 | 0 | 670.7(519\~753) | 51.16% | 200명 모두 통과 | 42,793 |

`results/csv/v5_render.csv`. MatrAIx 렌더러는 값이 "없음" 목록(None, Not applicable, Not a developer, No coding activity 등)에 들거나 속성의 기본값(`defaultValue`)과 같으면 그 속성을 빼므로(7.10절), 한 사람당 속성의 절반 넘게 제외된다. 가장 자주 제외되는 것은 개발 도구와 프로그래밍 언어(`tool_git`, `tool_github`, `prog_rust` 등, 최종 표본 2,000명 가운데 거의 전원)인데, 비개발자의 개발 속성이 Never used, None, Not applicable이기 때문이다(7.6절). 한국 렌더러는 값을 하나도 제외하지 않는다.

예시 프롬프트는 저장하지만 코드 변경 전후를 자동 비교하지는 않는다. 또한 누락 여부만 검사하며, 모델이 프로필의 속성을 이해하고 응답에 반영하는지는 확인하지 않았다.

### 가치 → 태도 연결

KGSS 블록의 태도 속성은 가치 점수에 연결된다(6.3절). `validate/value_link_check.py`는 이 연결이 실제의 가치–태도 관계를 얼마나 재현하는지 평가한다. 대상은 80% 모형에서 연결이 있는 속성 가운데 명목 속성 3개(종교, 종교성, 가장 가깝게 느끼는 나라)를 뺀 23개이고, 가치 10개와 곱해 230쌍이다. 분리분은 KGSS 2021년 검증 쪽에서 가치 문항 22개에 모두 답한 응답자이며, 가치 $j$의 점수를 생성과 같은 척도(80% 모형의 $\bar v_j$, $\mathrm{sd}_j$로 이중 중심화 및 표준화)로 생성한 뒤 범주 번호와의 가중 피어슨 상관을 산출한다. 생성 쪽은 `val_on`(연결 있음)과 `val_novl`(연결 없음)의 내부 가치 점수와 KGSS 범주 번호의 상관이다.

같은 스크립트는 가치 점수의 상관도 비교한다. Schwartz 원형에서 마주 보는 5쌍과 이웃한 10쌍, 모두 15쌍에서 KGSS 2021년 집단 내 상관과 생성 표본의 전체 상관의 차이는 평균 0.018, 최대 0.033(보편주의–자기주도, −0.017 대 −0.050)이다.

### 성격과 가치 수준의 비율

렌더러의 상대 위치 안내 문장(`LEVEL_GUIDE`, 7.10절)은 성격 범주를 아래부터 6.5%, 24%, 39%, 24%, 6.5%, 가치 범주를 5.5%, 23%, 43%, 23%, 5.5%로 기록한다. 최종 표본에서 직접 집계한 값(결과 파일에는 없음)은 BFI-2, IPIP 성격 속성 50개(`bfi2_*`, `big5_*`)의 평균이 Very low 6.52%, Low 23.94%, Average 38.96%, High 23.98%, Very high 6.60%(속성별 Very low 6.2\~6.8%), Schwartz 가치 10개의 평균이 5.50%, 22.90%, 43.22%, 23.00%, 5.38%로 안내 문장과 맞는다.

### 샘플러 일치

`tests/test_sampler.py`는 한국 속성을 하나도 고정하지 않은 `KRSampler`(5만 명)와 MatrAIx `sample_indices`(5만 명)의 속성별 총변동거리를 MatrAIx끼리 두 번 추출한 거리와 비교한다(7.2절). 속성별 거리는 중앙값 0.0038, 최대 0.0114(`hob_skydiving`)이고, MatrAIx끼리는 중앙값 0.0039, 최대 0.0129다(산출물 폴더 `artifacts/logs/sampler_check.log`). 한국 속성을 고정하지 않으면 두 추출기의 차이는 표본 잡음 수준이다.

## 9.9 평가 범위

- 학습 및 검증 분할은 조사 자료의 원자료 행을 선별하기 전에 수행한다. 분석 대상 안의 검증 비율은 정확히 20%가 아니며, 센서스는 가구 단위로 분할한다.
- 분포 거리의 평균은 최소 30행 조건을 만족한 조합에 한정한다. KGSS의 3개 속성 조합은 1,500개를 추출한다.
- 구분 가능성은 결정나무 분류기 하나로 평가한다.
- 모순 규칙은 생성기 수정에도 사용했으므로 현재 결과는 완전히 독립적인 검증이 아니다(8장).
- 65세 이상 비율은 센서스 검증 자료의 성인을 기준으로 비교한다. 인구 구성을 2025년 집계에 맞추는 보정은 적용하지 않았다.
- 렌더링 검사는 속성의 전달 여부에 한정하며, 모델의 이해도는 평가하지 않았다.
- MatrAIx 비교 표본은 공개 Persona 1M 파일이 아닌 공식 샘플러의 재생성 표본이다.

## 9.10 한계

- 실제 자료와 비교하는 속성은 한국 속성 83개뿐이다. MatrAIx 속성 1,069개의 분포와 그 속성들이 한국 속성과 맺는 관계는 실제 자료로 확인되지 않는다. 한국 속성 쌍도 3,403쌍 가운데 1,900쌍은 함께 측정한 자료가 없다.
- 조사 분리분은 나이로만 거르고 국적과 출생지는 거르지 않는다. 지역별고용조사와 가계금융복지조사는 2025년 자료이고 페르소나는 2020년 구성이므로 그 차이가 ①②에 섞인다.
- 장애 유형의 언어장애 처리가 검증 코드(Sensory)와 생성기(Physical)에서 다르다.
- 표본오차 기준은 생성 분포를 참으로 두고 Kish 유효 표본 수로 계산하며, 생성 표본의 잡음과 가중을 넘는 설계 효과를 무시한다. "생성 ÷ 기준"은 평균의 비다.
- MatrAIx의 ①②에는 분포 차이만이 아니라 범주 어휘의 차이가 들어 있다(예: MatrAIx `company_size`는 Solo / freelance와 Public sector만 한국 규모 구간과 겹친다). MatrAIx 평균과 생성 표본 평균은 조합 집합이 다르다.
- 작은 자료(국민건강영양조사, KGSS, 가계금융복지조사)의 pMSE 기준선은 같은 행의 복제 때문에 커지는 쪽으로 치우칠 수 있다.
- KGSS 비교는 두 속성을 함께 물은 해의 응답자로 하는데 생성은 여러 해를 혼합한다. KGSS 2개 조합의 응답자 수는 중앙값이 216명이다.
- ④의 공식 기준값은 코드에 저장된 상수이며 원 출처를 다시 확인하지 않았다. 1인 가구 지표는 계산 방식 때문에 가구 기준 공식값과 직접 비교할 수 없다.
- 가치–태도 점검과 영어 능력 점검은 응답자가 적고(쌍당 약 213명, 출생 연도 구간당 27\~61명), 가치–태도 점검은 범주 번호를 등간 척도처럼 사용한다.
- 조사 분포와의 대조(`compare.py`)는 추정에 사용한 자료와의 비교라 독립 검증이 아니다.
- 검증 모드에서도 사후층화 목표, 성격과 가치 점수의 중심, 사회단체 참여율, KGSS 블록 구조, MatrAIx 금지 규칙의 분류는 원자료 100%로 정한다. 지역별고용조사 A형과 B형은 분리 이름이 달라 분리한 응답자가 서로 다르다. 고령화연구패널은 나누지만 검증에 사용하지 않는다.
- MatrAIx 비교 표본은 `cult_south_korea` = Native인 성인이며 18세를 포함하고, 공개 Persona 1M이 아니다.
- 렌더링 점검의 고정 예시 파일은 실행할 때마다 덮어쓰며, 코드가 바뀔 때 비교하는 절차가 없다.
