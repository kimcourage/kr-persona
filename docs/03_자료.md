## 3.2 원자료 준비

원자료는 이 저장소에 포함하지 않는다. 일반적인 페르소나 생성에는 `bundle/`의 사전 추정 모형과 생성 입력을 사용하므로 원자료가 필요하지 않다. 모형 재추정이나 실제 자료와의 검증을 수행할 때에는 각 제공처의 이용 조건에 따라 원자료를 직접 준비해야 한다. 센서스 원자료 분석표 `artifacts/census/H.parquet`, `P.parquet`와 추정 중간 산출물은 `artifacts_dir`에 저장한다. `.gitignore`는 원자료와 산출물을 제외하고, `bundle/MANIFEST.json`에 명시한 생성용 파일만 예외로 포함한다. 묶음의 구성과 검토 범위는 10.13절에 제시하였다.

`config/paths.example.toml`을 `config/paths.toml`(git이 추적하지 않음)로 복사하고 세 디렉터리를 기록한다.

| 설정 | 환경 변수 | 내용 |
|---|---|---|
| `data_dir` | `KRP_DATA` | 원자료. 아래 표의 상대 경로로 파일을 배치한다 |
| `artifacts_dir` | `KRP_ARTIFACTS` | 파이프라인이 사용하는 모든 산출물 |
| `matraix_dir` | `KRP_MATRAIX` | MatrAIx checkout(커밋 `3633d8d`, 2장) |

설정 파일 자체의 위치는 `KRP_CONFIG`로 바꿀 수 있다. `data_dir` 아래의 파일 이름은 `config/data_files.toml`에 있다.

CSV 파일 이름 끝의 날짜와 번호는 내려받을 때 붙은 것이므로, 다른 사용자가 받은 파일은 이름이 다르다. 이때는 파일 이름을 변경하지 말고 `data_files.toml`만 고치면 된다. 인구 파일 이름의 `2__`는 원래 이름의 `%`가 바뀐 것이며 받은 그대로 두었다. 열 이름은 제공처의 공공용 파일설계서를 따른다고 가정하므로, 같은 조사라도 다른 연도나 다른 제공 형식의 파일은 코드를 수정하지 않고는 처리할 수 없다.

## 3.3 인구주택총조사 2020년 2% 표본

인구 파일(926,967명, 90개 항목)과 가구 및 주택 파일(418,594가구, 58개 항목)은 가구일련번호로 모두 연결된다. 두 파일은 일반가구만 담고 있으며, 만연령은 0\~84세는 각 세, 85세 이상은 한 값이다. 직업과 산업은 대분류(1자리)만 제공되고, 근로시간과 구직 여부 항목은 없다. 분석표를 만드는 방법(`census/prep.py`), 가상 인구 생성, 노출 통제는 5장에 있다. CART 기반 가상 인구 생성에는 아동, 외국인, 국외 출생자를 포함한 모든 행을 사용하고, 페르소나 대상자는 추출 단계에서 정한다.

페르소나 대상 인구는 출생 시와 현재 모두 대한민국 국적(`출생국적_대한민국여부 = 1`, `현재국적_대한민국여부 = 1`), 국내 출생(`출생지구분코드 ≠ 4`, 북한, 외국 출생 제외), 만 19세 이상이다. 원자료에서 771,930명이며 인구가중값 합은 40,425,221이다.

가중치는 두 가지를 사용한다. 가구가중값은 CART 기반 가상 인구 생성과 점검, 그리고 검증의 실제 쪽 비교 통계에 사용한다(개인 수준 통계에도 가구가중값을 사용한다, 5.1절). 인구가중값은 원자료 인구 파일을 직접 불러와 수행하는 다음 계산에 사용한다.

| 함수 | 참조 항목 | 용도 |
|---|---|---|
| `census/aggregates.py`의 `poststrat_from_raw` | 성별, 만연령, 행정구역시도, 국적 2개, 출생지, 인구가중값 | 성 × 5세 연령 × 시도 510칸의 사후층화 목표(5.6절) |
| `blocks/pers.py`의 `center` | 성별, 만연령, 국적 2개, 출생지, 인구가중값 | 성격 점수의 대상 인구 평균을 0으로 맞춤(6장) |
| `blocks/values.py`의 `center` | 위 항목과 교육정도, 수학구분 | 가치 점수의 대상 인구 평균을 0으로 맞춤(6장) |
| `census/aggregates.py`의 `participation_from_raw` | 위 항목과 사회분야 단체 참여 여부(20세 이상) | 성 × 연령 × 학력 칸별 사회단체 참여율(자원봉사 2단계 규칙, 6장) |
| `blocks/family.py`의 점검 출력 | 성별, 만연령, 혼인 상태, 출산, 사망 자녀 수, 국적, 출생지 | 기혼 여성의 생존 자녀 수를 KLoSA와 비교(추정에는 사용하지 않음) |

## 3.4 국민건강영양조사 2022년

`HN22_ALL.sav`는 2022년 조사 대상자 6,265명(모든 연령)과 700개 변수를 담는다. 분석 대상은 만 19세 이상이고 건강설문, 검진조사 가중치 `wt_itvex`가 양수인 5,322명이다(`blocks/health.py`의 `load`). 국적이나 출생지 조건은 걸지 않는다. 가중치는 `wt_itvex`다. PHQ-9 9문항이 모두 응답된 성인은 4,845명, GAD-7 7문항이 모두 응답된 성인은 5,238명, 둘 다인 성인은 4,828명이다. 파일에는 이 변수들의 값 라벨이 없으므로 코드는 이용지침서의 코드 정의를 따라 해석한다.

| 구분 | 변수 | 만드는 값 |
|---|---|---|
| 배경 | `sex`, `age`, `edu`, `marri_1`, `marri_2`, `EC1_1`, `EC_stt_1`, `ho_incm`, `town_t`, `genertn`, `cfam` | 성, 연령, 학력 4단계, 혼인 4단계, 취업, 종사상 지위, 가구소득 4분위, 동, 읍면, 가구 세대 구성 |
| 건강 | `D_1_1`(주관적 건강), `BP1`(스트레스 인지), `BS1_1`, `BS3_1`(흡연), `BD1`, `BD1_11`(음주), `BE3_31`(1주일간 걷기 일수), `DI1_dg`, `DI2_dg`, `DE1_dg`, `DJ4_dg`, `DN1_dg`(고혈압, 이상지질혈증, 당뇨병, 천식, 콩팥병 의사 진단) | `health_general_health`, `health_stress_level`, `lstyle_smoking`, `lstyle_alcohol_use`, `lstyle_exercise_freq`, `health_chronic_condition` |
| 증상 | `BP_PHQ_1`\~`BP_PHQ_9`, `BP_GAD_1`\~`BP_GAD_7`(0\~3만 유효) | `kr_depression_level`, `kr_anxiety_level`, 그리고 규칙으로 `health_mental_health` |

운동 빈도는 걷기 일수로, 만성 질환은 진단 다섯 가지의 수(0, 1, 2개 이상)로 근사한 것이다(6장).

## 3.5 가계금융복지조사 2025년

가구마스터(18,664가구, 160개 항목)와 가구원(41,154명, 13개 항목) 파일을 `MD제공용_가구고유번호`로 잇는다. 분석 단위는 가구이고 제한은 없다. 가구원 파일에서는 동거 코드가 1(1인 가구) 또는 2(같이 살고 있음)인 사람만 가구원으로 집계한다. 가중치는 가구 가중값(`가중값`)이다. 성인 단위로 사용하는 계산(사회경제 계층 5분위 경계, 검증의 실제 쪽 분포)은 가구 가중값에 동거하는 19세 이상 가구원 수를 곱한 값을 사용한다.

| 구분 | 변수 | 용도 |
|---|---|---|
| 가구주 | `가구주_성별코드`, `가구주_만연령`, `가구주_교육정도_학력코드`, `가구주_교육정도_수학구분코드`, `가구주_혼인상태코드`, `가구주_종사상지위코드`, `가구주_직업대분류코드(8차)` | 소득 모형의 부모 |
| 가구 | `가구원수`, `수도권여부`, `입주형태코드`, `부채_금융부채_담보대출_대출용도_거주주택구입금액`, `경상소득(보완)` | 소득(만원/년), 자가 여부, 거주 주택 구입 대출 |
| 가구원 | `가구원정보_동거코드`, `가구원정보_종사상지위코드`, `가구원정보_만연령` | 동거 취업자 수, 동거 성인 수 |

소득은 조사 전년도인 2024년 1년간의 경상소득이다. 이 자료로 `demo_household_income`(1,300원/달러 환산, 가정), `socioeconomic_band`의 경계(균등화 소득 $Y/\sqrt{\text{가구원 수}}$의 성인 5분위), 건강 블록에 사용하는 소득 4분위 경계, `demo_housing_status`의 Mortgage 여부를 생성한다. 이 파일에는 시도가 없고(수도권 여부만 있음) 가구원의 직업도 없다(가구주만 있음). 따라서 소득 모형은 가구주의 특성과 가구 구성만 부모로 사용한다.

## 3.6 지역별고용조사 2025년 상반기 A형과 B형

## 3.11 80% 학습, 20% 검증 분할

검증(9장)은 생성에 사용하지 않은 실제 자료와 비교하므로, 모든 원자료에서 20%를 분리한다. 환경 변수 `KR_HOLDOUT=1`을 주면 모든 추정이 나머지 80%만 사용하고 모형 파일 이름에 `_80`을 붙이며(`artifacts/models/<블록>_models_80.pkl`, `pers_params_80.json`, `value_params_80.json`), 생성기는 80% 가구로 생성한 센서스 기본 집단 `syn_s5_f0.8`을 사용한다. 최종 표본은 100% 모형과 `syn_s1`로 생성한다.

센서스는 가구 단위로 분할한다. 학습 가구는 `H.hid.sample(frac=0.8, random_state=5)`이며, 같은 호출이 CART 기반 가상 인구 생성(`census/synth.py`), 검증 자료(`validate/sources.py`의 `census`), 검증 모드의 모자 나이 차 분포(`Base4`)에서 되풀이된다. 학습 가구는 334,875가구, 검증 가구는 83,719가구이고, 페르소나 대상 인구는 학습 쪽 617,610명, 검증 쪽 154,320명이다.

조사 자료는 `blocks/core.py`의 `holdout_mask(name, n, frac=0.2)`로 분할한다. 원자료의 $i$번째 행은 다음 조건일 때 검증용이다.

$$
U_i < 0.2, \qquad U_1, \dots, U_n \sim \text{Uniform}(0,1) \text{ from } \texttt{numpy.random.default\_rng}(s), \qquad s = \text{MD5}(\text{name})\text{의 앞 16진수 8자리}
$$

나누는 행은 어떤 조건도 걸기 전의 원자료 행이며, 같은 자료 이름이면 모든 스크립트에서 같은 행이 제외된다. 따라서 실제 검증 비율은 분석 대상 안에서 정확히 20%가 아니다.

|---|---|---|---|---|---|
| `knhanes` | 4131128050 | 6,265 | 1,231 | `blocks/health.py` | 성인 5,322 / 4,249 |
| `eaps` | 3520647909 | 403,875 | 80,818 | `blocks/labor_income.py`(A형) | 사업체 규모 177,931 / 142,225, 임금 163,021 / 130,361 |
| `eaps_b` | 3679331195 | 403,875 | 80,783 | `blocks/dev.py`(B형) | 전문가 40,320 / 32,291 |
| `hfcs` | 1385634089 | 18,664가구 | 3,678 | `blocks/labor_income.py` | 18,664 / 14,986 |
| `kgss` | 1187450745 | 23,282 | 4,585 | `blocks/kgss.py`, `blocks/pers.py`, `blocks/values.py` | 분석 대상 23,017 / 18,477, 성격 4,423 / 3,516, 가치 1,177 / 963 |
| `klosa` | 2078149262 | 5,562 | 1,138 | `blocks/family.py` | 4,374 / 3,469 |

KGSS는 모든 연도의 행을 한꺼번에 나누며, 검증에는 2016\~2025년 응답자 가운데 검증 쪽 1,070명만 사용한다(9장). 성격, 가치, KGSS 블록이 같은 이름 `kgss`를 사용하므로 세 모형에서 같은 응답자가 제외된다. 지역별고용조사는 A형과 B형이 같은 응답자를 담지만 이름이 달라(`eaps`, `eaps_b`) 두 파일의 검증 행이 서로 다르다. 개발자 여부는 검증하지 않으므로 지금은 문제가 되지 않지만, A형 검증 자료로 개발자 여부를 비교하면 학습에 사용한 사람이 섞인다. 고령화연구패널도 나누지만 9장의 검증에는 사용하지 않는다. OECD 집계표와 문헌 값은 나누지 않는다.

다음은 100% 자료로 정한 뒤 검증 모드에서도 그대로 사용한다. 따라서 검증용 20%가 이 값들에 들어 있다.

- 센서스 사후층화 목표(성 × 5세 연령 × 시도)와 성격과 가치 점수의 중심, 사회단체 참여율(모두 원자료 인구 파일 전체에서 계산, 3.3절).
- KGSS 블록의 구조(추정 기간, 생성 연도, 부모 선택; 1단계에 전체 자료로 정함, 4.5절).
- MatrAIx 마스크의 분류(2.4절). 100% 가구로 생성한 `syn_s1`에서 생성한 0단계 페르소나로 판정했다.

## 3.12 실행에 필요하지 않은 자료

세계가치관조사 5, 6차 자료는 사용하지 않는다. 가치 모형은 KGSS 2021의 22개 문항(`VALUES1`\~`VALUES22`)으로 추정한다. KGSS 2005년 정서 문항(`POSAFF1`\~`POSAFF6`, `NEGAFF1`\~`NEGAFF4`)도 현재 성격 모형의 입력이 아니며, 성격 추정에는 TIPI 10문항을 사용한다.

파일설계서, 코드북과 이용지침서는 변수의 의미와 이용 조건을 확인하기 위한 참고 자료다. 실행 코드에서는 사용하지 않는다.

## 3.13 자료의 한계

시점이 자료마다 다르다. 페르소나의 기준 연도는 2020년이고 센서스도 2020년이지만, 소득은 2024년(가계금융복지조사 2025년), 노동은 2025년 상반기, 건강은 2022년, 고령화연구패널은 2024년(출생 코호트를 맞춰 4년을 뺌), 성격은 2009\~2012년, 가치는 2021년, 영어 능력은 2018년 자료다. KGSS 블록의 속성은 2020년 앞뒤 차수의 예측을 섞거나, 마지막 응답 연도가 2011년 이하이면 출생 코호트를 일치시킨다(4.5절). 소득과 임금은 물가나 임금 상승을 고려해 2020년 값으로 되돌리지 않았고, 달러 환산도 1,300원/달러 하나로 한다(가정).

모집단도 다르다. 페르소나 대상은 국내 출생 내국인 19세 이상이지만, 조사 자료에는 나이 조건만 걸었고 국적이나 출생지 조건은 걸지 않았다(국민건강영양조사, 지역별고용조사, KGSS). 가계금융복지조사는 가구 단위이고 가구주의 특성만 있으며, 고령화연구패널은 61세 이상만 담는다. 지역 정보도 자료마다 다르다. 가계금융복지조사는 수도권 여부만, 지역별고용조사 B형은 시도가 없고, 국민건강영양조사는 동, 읍면만 사용한다.

일부 측정은 근사다. 운동 빈도는 걷기 일수, 만성 질환은 진단 다섯 가지, 개발자 여부는 직업 소분류 다섯 개로 정한다. KGSS 성격 문항은 요인마다 문항이 둘뿐인 TIPI이며, 성격 측정 모형의 부하량은 직장인 표본(BFI-2)과 19\~50세 표본(IPIP)의 문헌 값, 신경증과 증상의 상관은 다발성 경화증 환자의 메타분석 값이다.

대응 워크북 `요약` 시트의 규모 수치(예: 성인 국내 출생 내국인 771,930명, 국민건강영양조사 PHQ-9 유효 4,845명)는 집계 결과를 옮겨 적은 값이며 집계 코드는 남아 있지 않다(4.6절). 이 장의 행 수와 분할 수치는 원자료와 저장된 모형 파일에서 다시 집계한 값이며, 워크북에 같은 항목이 있는 경우 값이 같았다.
