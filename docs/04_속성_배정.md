# 4. 속성 배정과 범주 대응

이 장은 MatrAIx 속성마다 어떤 방법으로 값을 생성하는지, 그리고 원자료 값을 MatrAIx 범주로 어떻게 옮기는지를 정한 내용을 설명한다. 결정은 대응 워크북 `mapping/변수대응표.xlsx`에 기록되어 있고, 코드는 이 워크북을 직접 불러온다. 워크북은 직접 관리하는 설정 파일이며 저장소에 포함된다.

## 4.1 대응 워크북

| 시트 | 내용 | 코드에서의 쓰임 |
|---|---|---|
| 요약 | 자료별 파일, 규모, 가중치, 연결 키, 용도, 확보 상태 | 없음(기록) |
| 범주 대응 | 속성마다 원자료 변수, 원자료 값, 출력 범주, 조건용 MatrAIx 범주(500행, 110개 속성 항목) | `generate/assign.py`가 조사 블록 속성 목록을, `mapping/kgss_codes.py`가 KGSS 변수 목록을 불러옴 |
| 새 한국 속성 | MatrAIx에 없는 한국 속성 후보 41개의 채택 또는 제외와 근거 | 없음(기록) |
| KGSS 블록 구성 | KGSS 블록 72개 속성의 추정 기간, 연도, 연령 처리, 부모 | `artifacts/mapping/kgss_analysis.pkl`과 같은 내용 |
| KGSS 연도 처리 근거 | 연도 처리 방식을 선택한 근거 표 2개 | 없음(기록) |
| 항목 점검 | 설계에 필요한 항목이 자료에 있는지 점검(33행) | 없음(기록) |
| 배경 변수 대응 | 성, 연령, 학력, 혼인 등 배경 변수의 자료별 변수 이름과 통일 방식 | 없음(기록) |
| 태도 블록 후보 | MatrAIx 태도 속성 30개의 KGSS 후보 문항 | 없음(기록) |
| KGSS 대응(속성별) | MatrAIx 속성 214개의 대표 KGSS 문항과 대응 강도 | 없음(기록) |
| KGSS 대응(전체 후보) | KGSS 문항 2,804개를 MatrAIx 속성과 의미로 대응한 1,060쌍 | 없음(기록) |

`범주 대응`, `새 한국 속성`, KGSS 블록 구성은 `docs/tables/category_mapping.csv`, `new_korean_attributes.csv`, `kgss_block.csv`로도 출력한다(`python -m krpersona.report.doc_tables`).

범주 대응은 문항의 의미를 검토해 정했다. 대응 강도는 같은 개념이면 “적합”, 근사에 해당하면 “부분”으로 구분한다. 워크북을 수정하면 관련 생성 및 추정 코드의 범주 정의도 함께 확인해야 한다. 초기 워크북 작성 스크립트는 실행 과정에 필요하지 않아 공개 패키지에서 제외했다.

## 4.2 다섯 가지 생성 방법

모든 출력 속성은 다음 가운데 하나로 생성한다. 개수는 `docs/tables/attributes.csv`(출력 속성 1,311개 = MatrAIx 출력 속성 1,290개 + 새 한국 속성 21개) 기준이다.

| 방법 | 개수 | 내용 |
|---|---|---|
| (1) 센서스 | 21 | 센서스 기반 가상 인구의 값을 MatrAIx 범주로 옮김(연령대, 성, 지역, 도시화, 학력, 혼인, 고용 상태, 국적 지위, 주거, 가구원 수, 통근 수단, 장애, 시각, 청각, 이동, 산업 분야, 직무, 혼인 기간, 지역 이동, 반려동물, 운전) |
| (2) 규칙 | 17 | 다른 값에서 정의로 계산(세대, 성장기 연대, 이민 세대, 민족, 문화 배경, 한국 문화, 한국어, 주 언어, 자녀 수, 부모 여부, 육아 경험, 생애 단계, 우세 성향, 경력, 직급, 정신건강, 소득 계층) |
| (3) 잠재 점수: 성격 | 52 | BFI-2 요인과 측면, IPIP-NEO 측면, MBTI, 사회적 배터리 |
| (3) 잠재 점수: 가치 | 10 | Schwartz 기본 가치 10개 |
| (3) 잠재 점수: 가치 문항 | 20 | `val_*` 가치 문항(가치 잠재 점수에서) |
| (3) 성격 점수에서 파생 | 37 | MatrAIx의 성격 및 선호 속성을 한국 성격 점수에서 만듦(3차 수정, 7장) |
| (4) 조사 추정 | 85 | 노동 및 소득, 건강, KGSS 블록 모형, 영어 능력, 개발자 여부, 새 한국 속성 21개 |
| (5) MatrAIx | 1,069 | 한국 값을 조건으로 MatrAIx 그래프에서 추출 |

(1)~(4)로 만드는 속성을 이 문서에서 "한국 속성"이라 하고(242개: 생성기 집합 $K$ 221개 + 새 한국 속성 21개), (5)를 "MatrAIx 속성"이라 한다. 생성기의 $K$는 `assign.build()`의 (1)~(3) 속성과 조사 블록 속성(0단계의 자리표시 속성 포함), Schwartz 가치 10개, 가치 문항 20개, 5단계에서 더한 40개(영어 능력 2개, 개발자 여부 1개, 성격에서 파생한 37개)의 합집합이다. 

## 4.3 범주 대응 규칙

`범주 대응` 시트의 한 행은 원자료 값 하나와 그 값의 출력 범주, 조건용 MatrAIx 범주를 기록한다.

- 출력 범주는 페르소나에 실제로 적히는 값이다. 조건용 MatrAIx 범주는 MatrAIx 그래프에 조건으로 넣는 값이다. 둘은 보통 같다.
- `{A, B}`처럼 여러 범주가 적힌 경우, 그 안에서 MatrAIx의 조건부 확률로 하나를 선택한다(예: 미혼 → {Single, In a relationship, Engaged}).
- MatrAIx에 맞는 범주가 없는 한국 값은 "직접 정의" 범주로 출력하고, 가장 가까운 MatrAIx 범주를 조건용으로 사용한다. 직접 정의 범주는 26개다: 고용 상태의 무급가족종사자(조건: Self-employed), 직무의 사무, 서비스, 판매, 농림어업, 기능원, 장치기계 조작, 단순노무, 기타(조건: Operations 등), 사업체 규모 6구간(1-4명 ~ 300명 이상; 조건: Startup/SMB/Mid/Enterprise), 종교의 원불교, 개신교, 천주교, 유교, 한국 신종교, 기타 종교, 종교성의 Nominal(조건: Spiritual), 정치 참여 4범주.
- 그 밖에 생성 과정에서 MatrAIx 범주 밖 값이 출력되는 경우는 주 언어 Korean, 산업 분야, 직급, 통근 수단의 Not applicable, 개발 전용 속성의 Not applicable과 개발자 여부의 Not a developer다. 조건용 범주가 없는 값(예: 주 언어 Korean)은 MatrAIx 그래프에서 "범주 없음"으로 처리되어 그 값에서 나가는 연결과 금지 규칙이 작동하지 않는다(7장).

주요 센서스 대응은 다음과 같다(전체는 `category_mapping.csv`).

- 연령대: 19~24세는 MatrAIx의 18-24로 출력한다(18세는 생성하지 않는다).
- 도시화: 서울과 6개 광역시의 동부 → Dense urban, 그 밖의 동부 → Suburban, 읍부 → Small town, 면부 → Rural.
- 학력: 교육 정도 × 수학 구분. 예: 4년제 졸업 → Bachelor's, 4년제 재학, 휴학, 중퇴, 수료 → Some college, 박사 졸업 → {Doctorate, Postdoc}.
- 고용 상태: 경제활동 × 종사상 지위 × 수학 구분 × 나이 × 결혼 전 취업, 경력 단절. 센서스에는 근로시간과 구직 여부가 없으므로 '틈틈이 일함'을 시간제의 대리 변수로, 60세를 은퇴와 가사의 경계로 사용한다(가정).
- 장애: 활동 제약 6개 항목에서 하나만 있으면 종류별(시각, 청각, 언어 → Sensory, 육체 → Physical, 정신, 지적 → Cognitive), 둘 이상이면 Multiple. 활동 제약은 등록 장애와 같지 않다(가정). 5단계 2차 수정에서 언어 장애만 있는 경우를 Physical로 바꿨다(검증 코드 쪽은 Sensory로 남아 있다; 10장).
- 경력: 현 직업 근속 구간의 하한 이상, (나이 − 15) 이하인 MatrAIx 구간 가운데 MatrAIx 확률로 선택한다.
- 혼인 기간: (나이 − 초혼 연령)으로 정하되 초혼 연령은 5세 구간 안에서 균등하게 추출한다. 재혼자의 혼인 기간도 초혼 시점을 기준으로 산정한다(가정).
- 가구소득: 가계금융복지조사 경상소득을 1,300원/달러로 환산해 MatrAIx 달러 구간에 배정한다. 소득 계층은 균등화 소득($Y/\sqrt{\text{가구원 수}}$)의 국내 5분위다.

KGSS 대응은 7점 동의 척도를 5범주로 묶는 규칙(매우 동의 → 1, 동의 → 2, 다소 동의, 중립 → 3, 다소 반대 → 4, 반대, 매우 반대 → 5)을 기본으로 하고, 속성마다 문항과 방향을 정했다. 문항이 MatrAIx 속성과 같은 개념이 아니고 근사인 경우(예: 데이터 프라이버시 태도 ← 여론조사 자료 보안 걱정, 권위 태도 ← 가부장 권위 문항)는 워크북에 "근사 문항(가정)"으로 표시했다.

## 4.5 KGSS 블록의 구조

KGSS 블록은 KGSS 2003~2025 누적 자료(23,282명, 17개 차수)에서 72개 속성(태도, 가치, 사회인식 53개, 새 한국 속성 19개)과 5단계에서 더한 영어 능력을 추정한다. 구조는 `mapping/kgss_analysis.py`가 정한다. 분석 표본은 19~100세, 성별 응답자 23,017명이다. 결측("모르겠다", "무응답", "비해당" 등 값 라벨과 음수)은 속성마다 따로 제외한다.

### 추정 기간과 생성 연도

문항마다 실린 연도가 다르다. 2016~2025년 유효 응답이 1,000명(한 차수 규모) 이상이면 그 기간만 사용하고, 아니면 전 연도를 사용한다. KGSS에는 2020년 차수가 없으므로, 생성할 때는 추정 기간 안에서 2020년 앞뒤의 가장 가까운 연도 $y_0 \le 2020 \le y_1$($y_1 - y_0 \le 7$)의 예측을 거리에 반비례해 혼합한다.

$$\hat p_{2020} = \frac{y_1 - 2020}{y_1 - y_0}\,\hat p_{y_0} + \frac{2020 - y_0}{y_1 - y_0}\,\hat p_{y_1}$$

예를 들어 2018년과 2021년이면 1:2로 혼합한다. 그런 연도 쌍이 없으면 2020년에 가장 가까운 연도를 사용한다. 마지막 응답 연도가 2011년 이하인 13개 속성(가치 문항 3개, 음악 장르 3개, 2007년 여가 문항 5개, 기부, 최우선 가치)은 출생 코호트를 일치시킨다. 즉 2020년 나이에서 (2020 − 조사 연도)를 뺀 나이(19세 하한)로 예측해, 같은 해에 태어난 사람의 당시 응답을 사용한다. 이 속성들은 신뢰도가 낮은 것으로 표시했다.

이 규칙의 근거는 `KGSS 연도 처리 근거` 시트다. 2003~2010년과 2016~2025년에 모두 1,000명 이상 응답한 43개 속성에서, 2016~2025년 응답자의 연령대별 분포 차이(TVD 평균)를 비교했다.

| 방법 | 중앙값(%p) |
|---|---|
| 전 연도, 연도 주효과 | 3.99 |
| 전 연도, 연령 × 시기 상호작용 | 1.76 |
| 2016~2025년만 | 1.83 |
| 2003~2010년 분포를 그대로 | 17.24 |
| 2003~2010년, 연령 고정 | 17.18 |
| 2003~2010년, 출생 코호트 고정 | 13.55 |

연도 주효과만으로는 최근 연령 분포를 맞추지 못하고, 최근 기간만 사용하는 것이 상호작용 모형과 비슷하므로 단순한 쪽을 골랐다. 10년 이상 지난 자료를 그대로 사용하면 13%p 이상 어긋나지만, 43개 중 34개(79%)에서 코호트 고정이 연령 고정보다 나았다.

### 블록 안의 부모

속성마다 블록 안에서 먼저 추정한 속성 가운데 최대 3개를 부모(조건 변수)로 설정한다.

1. 순서: 핵심 13개(종교, 종교성, 정치 성향, 주관적 계층, 북한관, 통일 필요성, 기관 신뢰, 언론 신뢰, 대기업 신뢰, 종교계 태도, 노조 태도, 애국심, 가장 가까운 나라)를 먼저 두고, 나머지는 추정 기간의 유효 응답이 많은 순서로 배치한다.
2. 부모 자격: 앞선 속성 가운데 그 속성의 응답자 90% 이상이 함께 응답한 속성.
3. 논리적 부모는 항상 포함한다: 종교성 ← 종교, 종교계 태도, 영성 관심, 신앙 경로, 영성 가치 ← 종교와 종교성, 통일 필요성 ← 북한관, 행복 ← 삶의 만족, 정치 참여, 정치 관심 ← 정치 성향.
4. 후보: 성 × 연령대 × 학력 × 조사 연도 층 안의 조건부 상호정보량 $\hat I(Y;X\mid S) = \hat H(Y\mid S) - \hat H(Y\mid S, X) - \sum_s (|Y_s|-1)(|X_s|-1)/(2n)$가 양수인 상위 8개(응답 300명 미만이면 제외).
5. 전진 선택: 성, 연령대, 학력, 연도와 현재 부모를 넣은 다항 로지스틱 회귀(L2, $C = 10$)에 후보를 하나 더했을 때 로그우도가 2% 이상 늘고 AIC도 좋아지면, 그중 가장 좋은 것을 더한다.

결과는 부모가 있는 속성 45개, 배경 변수만 사용하는 속성 27개다(부모 수 평균 0.92). BIC 기준이면 37개가 배경 변수만 사용하고, AIC만 사용하면 평균 2.5개로 약한 연결이 많아져, 2% 기준을 그 사이로 골랐다. 이 AIC 수치는 속성마다 대표 문항 하나로 부호화한 이전 스크립트의 결과라 최종 표와 정확히 같은 조건은 아니다.

블록 밖 부모: 건강 블록의 주관적 건강(에너지, 통증, 보험, 건강정보 이해력), 우울(보험; KGSS CES-D 2023년), 센서스 정치 단체 참여(정치 참여; KGSS 2004, 2014년 정당 활동 문항으로 효과를 따로 추정), 센서스 사회 단체 참여(자원봉사; 두 단계 규칙, 6장)를 사용한다. 이 연결들의 로그우도 개선은 0.4~7.3%로, 일부는 2% 기준보다 작지만 의미상 필요해 넣었다. 개선 값은 저장되지 않은 실행의 출력을 워크북에 옮겨 적은 것이다. 이 개선 값을 계산한 초기 분석에서는 CES-D 긍정 문항을 역코딩하지 않았다. 최종 추정 코드(`blocks/kgss.py`의 `load`)는 긍정 문항 4개(행복감, 즐거움, 활력감, 평온함)를 역코딩한다. 두 경우 모두 우울 점수는 사실상 2023년 응답자만으로 생성한다. 문항 9~11이 2023년에만 있고 점수에 10문항 이상을 요구하기 때문이다(6.8절).

## 4.6 알려진 문제

- 대응 워크북은 KGSS 성격 문항을 "BFI-10"이라 적었지만, 실제 문항은 TIPI(Gosling 외, 2003)의 형용사 쌍 10개다. 성격 모형(6장)은 TIPI로 처리한다. 워크북은 1단계 산출물이라 그대로 두었다.
- `lstyle_gaming_freq`는 2007년 문항(CULACT03)을 코호트를 맞춰 사용한다. 2025년 문항(USEGAMES)도 있으나 대응표에 반영하지 않았다.
- KGSS 구조 분석은 원자료 코드(묶기 전 범주)로 했고, 로지스틱 회귀에는 가중치를 사용하지 않았다. 표본 안 적합도이므로 2% 기준과 AIC는 근사다.
- `요약`과 `항목 점검` 시트의 숫자(예: 성인 국내 출생 내국인 771,930명)는 집계 결과를 옮겨 적은 값이며 집계 코드는 남아 있지 않다.
