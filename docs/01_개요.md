# 1. 개요

kr-persona는 한국 성인의 가상 페르소나를 만드는 생성기다. MatrAIx(https://github.com/MatrAIx-ai/MatrAIx-Persona-8B, commit 3633d8d)의 속성 체계와 확률 그래프를 그대로 쓰되, 한국 인구 구성과 한국 조사 자료로 정할 수 있는 속성은 한국 자료에서 정하고, 나머지 속성은 MatrAIx 그래프에서 한국 값에 조건을 걸어 추출한다. 출력은 MatrAIx와 같은 속성 id와 범주를 사용하므로 MatrAIx의 렌더러와 도구에서 별도 변환 없이 처리할 수 있다.

## 1.1 모집단과 시점

페르소나의 모집단은 국내에서 태어난 대한민국 국적자 가운데 19세 이상이다. 인구 구성(나이, 성, 지역, 학력, 가구, 취업, 혼인)과 출생 연도로 정해지는 속성(세대, 성장기 연대)은 2020년 11월 1일 인구주택총조사 기준이다. 기술, 제품, AI 도구의 사용과 현재 생활 습관은 생성 시점(현재)을 묘사한다. 따라서 한 페르소나는 "2020년 인구 구성의 한 사람이 지금의 기술 환경에서 사는 모습"으로 해석해야 한다. 성별, 연령, 지역을 최근 집계에 다시 맞추는 보정은 하지 않았다(10장).

정확한 나이, 시도, 가구 안의 관계 같은 내부 값은 생성 과정에서 쓰지만 출력 속성에는 포함하지 않는다. 출력 속성에는 MatrAIx의 연령대(`age_bracket`)와 도시화(`urbanicity`) 같은 범주만 있다.

## 1.2 속성과 생성 방법

출력 속성은 1,311개다. MatrAIx 속성 1,290개 가운데 221개(한국 속성 집합 $`K`$)를 한국 자료와 규칙으로 정하고, MatrAIx에 없는 한국 속성 21개(`kr_*`)를 더했다. 속성마다 다섯 가지 생성 방법 가운데 하나가 배정된다(4장).

| 방법 | 속성 수 | 내용 |
|---|---|---|
| (1) 센서스 | 21 | 센서스 기반 가상 인구의 값을 MatrAIx 범주로 옮긴다(5장). |
| (2) 규칙 | 17 | 다른 값에서 정의로 계산한다(7장). |
| (3) 잠재 점수 | 82 | 성격 52개, Schwartz 가치 10개, 가치 문항 20개(6장). |
| (3) 성격 점수에서 파생 | 37 | MatrAIx의 성격 및 선호 속성을 한국 성격 점수에서 생성한다(7장). |
| (4) 조사 추정 | 85 | 건강, 노동, 소득, KGSS, 영어 능력, 개발자 여부, 새 한국 속성 21개(6장). |
| (5) MatrAIx | 1,069 | MatrAIx 그래프에서 한국 값에 조건부로 추출한다(7장). |

한국 속성 집합 $`K`$는 센서스, 규칙, 조사 모형의 181개 속성에 성격 파생 속성 37개와 영어 능력, `lang_english`, 개발자 여부를 더한 221개다.

## 1.3 처리 흐름

```
MatrAIx 그래프(full_dag.json) ──────────────────────────────┐
                                                             │
인구주택총조사 2020 2% ─▶ 순차 CART 기반 가상 인구 생성 ─▶ 페르소나 추출(성×5세×시도 사후층화)
                                                             │
                               (1) 센서스 대응, (2) 규칙 ◀───┤
조사 자료 ─▶ 블록 모형(성격, 가치, 건강, 노동 및 소득, KGSS, 가족, 개발자) ─▶ (3)(4)
                                                             │
                       수정 샘플러 KRSampler: (5)를 한국 값에 조건부로
                                                             │
           금지 규칙(생성 중) ─▶ 재추출(MatrAIx 부분) ─▶ 거부 검사 ─▶ 출력
                                                             │
              검증: 검증용 실제 20%와 비교, 모순 규칙 세트, 렌더링 누락
```

## 1.4 단계와 실행

사전 추정 모형으로 생성만 수행할 때는 README의 빠른 시작 절차를 사용한다. 아래 단계는 원자료에서 재추정하고 검증하기 위한 절차다.

모든 단계는 저장소 루트에서 `bash scripts/NN_*.sh`로 실행한다. 경로는 `config/paths.toml`(예시 `config/paths.example.toml`)에 원자료 폴더, 산출물 폴더, MatrAIx 위치를 적어 정한다. 원자료 파일 이름은 `config/data_files.toml`에 있다.

| 스크립트 | 모듈 | 입력 | 출력(산출물 폴더 안) | 문서 |
|---|---|---|---|---|
| `01_baseline.sh` | `krpersona.baseline` | MatrAIx | `baseline/`: MatrAIx 재현 표본 100만 명, 한국 문화 Native 성인 37,237명, 진단 결과 | 2장 |
| `02_mapping.sh` | `krpersona.mapping` | KGSS, `mapping/변수대응표.xlsx` | `mapping/kgss_analysis.pkl` | 4장 |
| `03_census.sh` | `krpersona.census` | 인구주택총조사 | `census/`: 분석표, 생성 참조값(`aggregates.pkl`), 가상 인구 3종, 점검 결과 | 5장 |
| `04_blocks.sh` | `krpersona.blocks` | 조사 자료 전체 | `models/`: 전체 자료 모형과 80% 모형(`_80`) | 6장 |
| `05_masks.sh` | `krpersona.matraix.classify_masks`, `krpersona.generate.compile_masks` | 기본 생성기의 시험 표본, 기준 표본 `test5` | `masks/mask_class.pkl`, `masks/rule_masks.pkl` | 7장과 8장 |
| `06_generate.sh` | `krpersona.generate.run` | 모형, 센서스 기반 가상 인구, 금지 규칙 | `samples/val_on`, `val_novl`, `out_on`, `out_off` | 7장 |
| `07_validate.sh` | `krpersona.validate` | 표본, 원자료 20% 분리분, 규칙 세트 | `validation/` | 8장과 9장 |
| `08_results.sh` | `krpersona.report` | `validation/`, `census/`, 표본 통계 | 저장소의 `results/`, `docs/tables/` | 9장 |
| `09_bundle.sh` | `krpersona.report.bundle` | 전체 자료 모형, 금지 규칙, 센서스 기본 집단과 집계표 | 저장 형식 확인 후 `bundle/` 갱신(별도 실행) | 10.13절 |

표본은 네 가지다. 검증 표본 `val_on`은 모든 자료에서 20%를 분리하고 나머지 80%로 가상 인구를 생성하고 모형을 추정해(`KR_HOLDOUT=1`) 생성한 2만 명이고, 분리한 20%와 비교하는 데 사용한다. `val_novl`은 같은 조건에서 가치 → KGSS 태도 연결을 끈 것이다(`KR_NO_VLINKS=1`). 최종 표본 `out_on`은 전체 자료 모형으로 생성한 2만 명이고, `out_off`는 MatrAIx 속성 없이 한국 속성만 생성한 5천 명이다.

검증은 현재 검증 및 최종 표본만으로 실행할 수 있다. `artifacts_dir/samples/history/`에 추가 비교 표본이 있으면 함께 포함한다. 이 표본들은 배포 파일에 포함되지 않는다. 규칙 종류는 첫 입력 표본에서 규칙이 참조한 열로 분류하므로, 입력 표본에 따라 저장된 결과와 분류가 일부 다를 수 있다(8.3절).

기존 수치와의 재현 조건도 구분해야 한다. 배포된 표를 재현하려면 계산에 사용한 모형과 고정 기준 표본이 필요하다. 금지 규칙 컴파일의 기준 표본 `test5`를 현재 생성기로 새로 생성하면 규칙이 달라질 수 있다(8.5절). 따라서 전체 실행이 기존 표의 모든 수치를 그대로 복원하는 절차는 아니다.

보고된 실행 환경은 Python 3.13.16, numpy 2.5.3, pandas 3.0.5, scipy 1.18.1, scikit-learn 1.9.1, torch 2.15.0(CPU)이다. 2코어 환경에서 전체 및 80% 모형 추정은 1시간 이상, 표본 네 개 생성은 약 12분, 검증은 약 10분이 걸렸다. 실행 시간과 난수 및 최적화 결과는 환경에 따라 달라질 수 있다.

## 1.6 용어

- 한국 속성: 한국 자료나 규칙으로 정하는 속성. MatrAIx 속성 가운데 $`K`$에 든 221개와 새 한국 속성 21개.
- MatrAIx 속성: (5)로 MatrAIx 그래프에서 추출하는 1,069개.
- 직접 정의 범주: MatrAIx 범주 목록에 맞는 것이 없어 한국 값으로 출력하는 범주(예: 고용 상태의 `Unpaid family worker`). 그래프 안에서는 가장 가까운 MatrAIx 범주를 조건으로 사용한다.
- 금지 규칙(마스크): 생성 중에 어떤 조건에서 특정 값의 확률을 0으로 두는 규칙.
- 모순 규칙 세트: 속성 정의를 바탕으로 구성한 일관성 검사 규칙. 생성기 코드와 분리해 구성했으나, 이후 생성기 수정에도 사용했으므로 현재 결과는 완전히 독립적인 검증이 아니다(8장).
- 80% 모형: 모든 자료에서 같은 방식으로 20%를 분리하고 추정한 모형. 검증 표본에만 사용한다.
